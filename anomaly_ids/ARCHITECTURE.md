## Configuration (`pipeline/config.py`)

All hyperparameters are centralised in the `IDSConfig` class.
An optional `config_dict` can override any default at construction time.

| Parameter               | Default        | Purpose                                                     |
|--------------------------|----------------|-------------------------------------------------------------|
| `use_autoencoder`        | `True`         | Enable autoencoder for feature compression                  |
| `use_pca_features`       | `True`         | Enable PCA (fallback if AE disabled)                        |
| `anomaly_detectors`      | `[IF, LOF]`    | Which unsupervised detectors to train                       |
| `supervised_weight`      | `0.65`         | RF weight in ensemble (higher = trust RF more)              |
| `ensemble_method`        | `weighted_avg` | How to combine RF + unsupervised scores                     |
| `optimize_weights`       | `False`        | Auto-tune weight & threshold on validation set              |
| `ae_encoding_dim`        | `32`           | Bottleneck dimension of autoencoder                         |
| `ae_epochs`              | `10`           | Training epochs for autoencoder                             |
| `ae_batch_size`          | `256`          | Batch size for autoencoder                                  |
| `ae_dropout`             | `0.2`          | Dropout rate in autoencoder                                 |
| `iso_n_estimators`       | `100`          | Number of Isolation Forest trees                            |
| `iso_max_samples`        | `256`          | Samples per IF tree                                         |
| `iso_contamination`      | `0.15`         | Expected anomaly proportion for IF                          |
| `iso_max_features`       | `0.7`          | Feature fraction per IF tree                                |
| `lof_n_neighbors`        | `20`           | LOF neighbor count                                          |
| `lof_contamination`      | `0.15`         | Expected anomaly proportion for LOF                         |
| `lof_max_samples`        | `50,000`       | LOF-specific training row cap (O(n·k·log n))               |
| `unsupervised_max_samples`| `200,000`     | Cap for IF and AE training rows                             |
| `rf_max_samples`         | `500,000`      | Cap for RF training rows (AE encoding is the bottleneck)    |
| `rf_n_estimators`        | `50`           | Number of RF trees                                          |
| `rf_max_depth`           | `15`           | Maximum tree depth                                          |
| `rf_min_samples_split`   | `20`           | Minimum samples to split a node                             |
| `rf_min_samples_leaf`    | `10`           | Minimum samples in a leaf                                   |
| `rf_max_features`        | `sqrt`         | Features considered per split                               |
| `rf_class_weight`        | `balanced`     | Auto-balance class weights                                  |
| `pca_n_components`       | `0.95`         | PCA variance retention                                      |
| `correlation_threshold`  | `0.95`         | Drop features with correlation above this                   |
| `default_threshold`      | `0.50`         | Classification threshold (prob ≥ threshold → intrusion)     |

## Training Flow (`train.py` → `pipeline.py`)

### Entry Point: `train.py __main__`

```
[1] Auto-detect CSV files in training/ directory
      • KDDTrain.csv + KDDTest.csv found? → two-file mode
      • Otherwise → pick first .csv, auto-split 80/20
```

### `train_hybrid_ids()` — 5 outer steps

#### Step 1/5 — Load Data
- Read CSV file(s)
- Strip whitespace from column names (fixes `ct_src_ ltm` → `ct_src_ltm`)
- Single file mode: `train_test_split(test_size=0.2, random_state=42, shuffle=True)`

#### Step 2/5 — Create Binary Targets
- Auto-detect label column by scanning: `attack_class`, `label`, `class`, `target`, `attack`, `intrusion`
- Auto-detect normal class:
  - If `"normal"` found in unique values → string comparison
  - If `0` found and column is integer dtype → integer comparison
- Create binary column: `is_intrusion = (label != normal).astype(int)`
- Track novel attacks: attacks present in test but absent from train

#### Step 3/5 — Prepare Features
- `X = df.drop("is_intrusion")`
- `y = df["is_intrusion"]`

#### Step 4/5 — Train/Val Split
- `train_test_split(test_size=0.2, stratify=y, random_state=42)`
- Result: `X_train`, `X_val`, `y_train`, `y_val` (plus `X_test`, `y_test` from step 1)

#### Step 5/5 — Train Pipeline
- `pipeline.fit(X_train, y_train, X_val, y_val, verbose=2)`

### `pipeline.fit()` — 10 inner steps

#### [1/10] Preprocessing (`preprocessor.fit_transform`)

```
fit():
  ├── Auto-detect categorical columns (object dtype)
  │     KDD: protocol_type, service, flag (hardcoded)
  │     UNSW: proto, state, service (auto-detected)
  └── Find columns to drop: constant (nunique=1) or all-unique (nunique=len)

transform():
  ├── Drop label columns: attack_class, attack_class_category, label, attack
  ├── Drop constant/all-unique columns
  ├── pd.get_dummies() on categorical columns (one-hot encoding)
  │     → bool columns cast to int8 (pandas 2.x compatibility)
  └── Store training_columns for future alignment (inference)
```

**Output:** DataFrame with ~160 columns (after one-hot expansion)

#### [2/10] Feature Engineering

```
add_statistical_features():
  ├── Alias UNSW column names: Sload→sload, Spkts→spkts, Sjit→sjit, etc.
  ├── KDD features:
  │     bytes_ratio = src_bytes / (dst_bytes + 1)
  │     total_bytes = src_bytes + dst_bytes
  │     srv_ratio   = srv_count / (count + 1)
  │     packet_rate = count / (duration + 1)
  └── UNSW features:
        bytes_ratio    = sbytes / (dbytes + 1)
        pkt_ratio      = spkts / (dpkts + 1)
        total_pkts     = spkts + dpkts
        bytes_per_pkt  = (sbytes + dbytes) / (spkts + dpkts + 1)
        load_asymmetry = |sload - dload| / (sload + dload + 1)
        jit_asymmetry  = |sjit - djit| / (sjit + djit + 1)

add_context_aware_features():
  ├── KDD features:
  │     bytes_per_connection, connection_regularity, service_focus,
  │     host_diversity, byte_asymmetry, total_error_rate,
  │     normalized_packet_rate, legitimacy_score
  └── UNSW features:
        handshake_efficiency = (synack + ackdat) / (tcprtt + 1)
        connection_density   = ct_dst_src_ltm × ct_srv_dst
        src_byte_rate        = sbytes / (dur + 1)
        response_efficiency  = response_body_len / (dbytes + 1)
        ttl_asymmetry        = |sttl - dttl|
```

**Output:** DataFrame with ~175 columns

#### [3/10] Drop Correlated Features

```
drop_correlated_features(X, threshold=0.95):
  ├── Drop any remaining non-numeric columns (safety net)
  ├── Sample 50K rows (corr on 2M rows is O(n × f²))
  ├── Compute correlation matrix (numeric_only=True)
  ├── Upper triangle mask → find pairs with |r| > 0.95
  └── Drop one column from each highly-correlated pair
```

**Output:** DataFrame with ~100 columns; `self.feature_names` stored

#### [4/10] Scaling

```
├── X.astype('float32')
├── RobustScaler.fit_transform(X) → numpy array X_train_scaled
├── Extract normal rows: X_normal_train = X_train_scaled[y_train == 0]
└── Cap normal samples for unsupervised training:
      X_normal_train_us = random sample of 200K normals (seed=42)
```

**Output:** numpy float32 array ~2M × ~100

#### [5/10] Autoencoder (trained on normal-only data)

```
Architecture:
  Input(N) → Dense(128, relu) → Dropout(0.2)
           → Dense(64, relu)  → Dropout(0.2)
           → Dense(32, relu)  ← BOTTLENECK (encoder output)
           → Dense(64, relu)  → Dropout(0.2)
           → Dense(128, relu) → Dense(N, linear)

Training:
  Loss: MSE (learn to reconstruct normal traffic)
  Optimizer: Adam
  Epochs: 10
  Batch size: 256
  Data: X_normal_train_us (≤200K normal rows)
  Validation: X_normal_val (if provided)

Outputs:
  encoder.predict(X) → 32-dim compressed features (for RF)
  reconstruction_error(X) → MSE per sample (for anomaly scoring)
```

#### [6/10] PCA

```
PCA(n_components=0.95, random_state=42)
  Fit on: X_normal_train_us
  Purpose: Fallback encoding if autoencoder is disabled
  NOT used for RF input when AE is enabled
```

#### [7/10] Anomaly Detectors (trained on normal-only data)

```
Isolation Forest:
  ├── n_estimators=100, max_samples=256, contamination=0.15
  ├── Fit on: X_normal_train_us (≤200K normal rows)
  └── score(X) = -score_samples(X)  (higher = more anomalous)

LOF (novelty=True):
  ├── n_neighbors=20, contamination=0.15
  ├── Separate cap: 50K rows from X_normal_train_us (seed=123)
  └── score(X) = -score_samples(X)  (higher = more anomalous)
```

#### [8/10] Supervised Model (Random Forest)

```
RandomForest:
  ├── 50 trees, max_depth=15, class_weight='balanced'
  ├── Cap training rows at 500K (stratified sample preserving attack ratio)
  ├── If AE enabled:
  │     X_encoded = autoencoder.encode(X_rf) → 32-dim
  │     RF.fit(X_encoded, y_rf)
  └── Else:
        RF.fit(X_rf, y_rf)  (raw ~100-dim features)

Note: RF is trained on MIXED data (both normal + attack labels)
```

#### [9/10] Normalizer + Weights/Threshold

```
Path A — optimize_weights=True AND X_val provided:
  ├── Score FULL X_val through IF + LOF → raw anomaly scores
  ├── normalizer.fit(scores) → learn p5, p95 per detector
  ├── Grid search: weight ∈ [0.1, 0.7] × threshold ∈ [0.2, 0.8]
  │     For each (weight, threshold):
  │       ensemble.predict_proba() → hybrid scores
  │       preds = (hybrid ≥ threshold)
  │       Skip if recall < 0.90 (floor constraint)
  │       Track best F1 score
  └── Store best_weight and best_threshold

Path B — optimize_weights=False (CURRENT DEFAULT):
  ├── Score 50K sample of X_val through IF + LOF (cap for speed)
  ├── normalizer.fit(scores) → learn p5, p95 per detector
  └── Use config defaults: supervised_weight=0.65, threshold=0.50

ScoreNormalizer mechanics:
  fit():    For each detector → store (p5_value, p95_value)
  transform(): normalized = clip((score - p5) / (p95 - p5 + ε), 0, 1)
```

#### [10/10] Create Ensemble

```
HybridEnsemble(supervised_weight=0.65, method='weighted_avg')

weighted_avg formula:
  avg_anomaly = mean(IF_normalized, LOF_normalized)
  hybrid_prob = 0.65 × RF_prob + 0.35 × avg_anomaly

max formula (alternative):
  max_anomaly = max(IF_normalized, LOF_normalized)
  hybrid_prob = max(0.65 × RF_prob, 0.35 × max_anomaly)
```

## Inference Flow (`app/main.py` → `pipeline.predict_proba`)

### API Startup

```
get_pipeline() → ModelManager.load_pipeline("latest")
  ├── Read config.json → IDSConfig(config_dict)
  ├── Load params.joblib → feature_names, correlated_features
  ├── Load preprocessor.joblib → fitted Preprocessor
  ├── Load scaler.joblib → fitted RobustScaler
  ├── Load pca.joblib → fitted PCA (if exists)
  ├── Load autoencoder.weights.h5 → rebuild Keras model, load weights
  │     Fallback: try autoencoder.keras (legacy format)
  │     Fallback: disable AE anomaly scoring (random weights)
  ├── Load anomaly_detectors.joblib → fitted IF + LOF
  ├── Load supervised_model.joblib → fitted RF
  ├── Load normalizer.joblib → fitted ScoreNormalizer (p5/p95)
  ├── Load ensemble.joblib → HybridEnsemble
  └── Load threshold_optimizer.joblib → ThresholdOptimizer
```

### Single Prediction (`POST /predict`)

```
Input: NetworkTrafficInput (Pydantic model, all fields optional)
  └── .to_dict() → only non-None fields

pipeline.predict_proba(df):
  │
  ├── _transform_features(X):
  │     ├── preprocessor.transform()
  │     │     Drop label cols, drop constant/unique cols
  │     │     get_dummies() on categoricals → int8
  │     │     Align to training_columns (fill missing with 0)
  │     ├── add_statistical_features()
  │     ├── add_context_aware_features()
  │     ├── Drop correlated_features (from saved list)
  │     ├── astype('float32')
  │     └── scaler.transform() → X_scaled (numpy)
  │
  ├── _get_supervised_probs(X_scaled):
  │     ├── autoencoder.encode(X_scaled) → 32-dim
  │     └── RF.predict_proba(X_encoded)[:, 1] → P(intrusion)
  │
  ├── _get_anomaly_scores(X_scaled):
  │     ├── IF.score(X_scaled)  → raw IF scores
  │     ├── LOF.score(X_scaled) → raw LOF scores
  │     └── (AE.reconstruction_error() only if weights_loaded=True)
  │
  ├── normalizer.transform(scores):
  │     For each detector: clip((score - p5) / (p95 - p5 + ε), 0, 1)
  │
  └── ensemble.predict_proba(sup_probs, anomaly_scores_norm):
        hybrid = 0.65 × RF_prob + 0.35 × mean(IF_norm, LOF_norm)

threshold_optimizer.predict(hybrid_prob):
  is_intrusion = (hybrid_prob >= 0.50)

determine_alert_level(prob, is_intrusion):
  ├── prob ≥ 0.90 → CRITICAL: "Immediate action required"
  ├── prob ≥ 0.70 → HIGH:     "Proceed with caution"
  ├── prob ≥ 0.50 → MEDIUM:   "Suspicious activity — action recommended"
  ├── prob ≥ 0.40 → LOW:      "Borderline anomaly — monitoring required"
  └── prob <  0.40 →
        is_intrusion=True?  → LOW:    "Low confidence — may be false anomaly"
        is_intrusion=False? → NORMAL: "No intrusion detected — normal traffic"

Response: PredictionOutput {
  is_intrusion, confidence, intrusion_probability,
  alert_level, alert_message
}
```

## Key Design Decisions

1. **Unsupervised models train on normal-only data** — LOF and IF learn the "shape" of normal traffic so they can flag anything outside that distribution as anomalous.

2. **Supervised model trains on mixed data** — RF sees both normal and attack rows to learn discriminative boundaries. It receives 32-dim AE-compressed features, not raw features.

3. **Ensemble uses weighted average** — `0.65 × RF + 0.35 × mean(IF, LOF)`. RF is dominant because it directly learned attack patterns; the unsupervised scores provide a safety net for novel attacks the RF hasn't seen.

4. **Score normalisation is percentile-based** — Raw IF scores (≈0.4–0.6) and LOF scores (≈1–100+) live on completely different scales. The normalizer maps both to [0, 1] using fitted p5/p95 percentiles.

5. **Training row caps** — LOF is O(n·k·log n), AE encoding is sequential through Keras, and correlation computation is O(n·f²). Each bottleneck has its own cap to keep total training time under 30 minutes.

6. **Column alignment at inference** — `preprocessor.transform()` uses `reindex(columns=training_columns, fill_value=0)` so predictions work even if the input has fewer or differently-ordered columns than training data.
