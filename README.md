# Anomaly_Detection_Cloned
Cloned version of original Anomaly_Detection model. Made for displaying mainly SHAP/LIME values accordingly.

# How to run the Model =>
=> Make the path point inside 'anomaly_ids' by using the statement -
   "cd anomaly_ids"

=> Perform Training of the model by first running -
   1.) "cd training"
   2.) "python train.py"

=> Now, run the api using -
   1.) python app\main.py
   (Default port is 8000)
